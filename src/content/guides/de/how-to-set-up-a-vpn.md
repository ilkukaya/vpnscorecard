Einen VPN einzurichten ist viel einfacher, als es klingt. Auf den meisten Geräten dauert es weniger als fünf Minuten.

## Schritt 1: Einen VPN auswählen

Wählen Sie einen Anbieter mit geprüfter No-Logs-Policy, Apps für all Ihre Geräte und einer Geld-zurück-Garantie, damit Sie ihn ausprobieren können. Unsere [Rankings](/) und unser [VPN-Finder-Quiz](/quiz/) helfen dabei. Meiden Sie unbekannte Gratis-VPNs aus App-Stores – siehe [Sind kostenlose VPNs sicher?](/guides/are-free-vpns-safe/)

## Schritt 2: Ein Konto erstellen

Registrieren Sie sich auf der offiziellen Website des Anbieters. Lange Laufzeiten sind pro Monat meist deutlich günstiger, doch ein Monatstarif ist in Ordnung, wenn Sie erst ausprobieren möchten. Merken Sie sich die Erstattungsfrist.

## Schritt 3: Die App installieren

Laden Sie Apps immer von der Website des Anbieters oder aus dem offiziellen App-Store herunter.

### Windows und Mac

1. Laden Sie das Installationsprogramm von der Website des Anbieters herunter.
2. Führen Sie es aus und folgen Sie den Anweisungen. Erlauben Sie unter macOS auf Nachfrage die VPN-Konfiguration.
3. Melden Sie sich mit Ihrem Konto an.

### iPhone und iPad

1. Installieren Sie die App des Anbieters aus dem App Store.
2. Melden Sie sich an und tippen Sie auf **Verbinden**.
3. Tippen Sie auf **Erlauben**, wenn iOS fragt, ob eine VPN-Konfiguration hinzugefügt werden soll.

### Android

1. Installieren Sie die App aus Google Play.
2. Melden Sie sich an, tippen Sie auf **Verbinden** und bestätigen Sie dann die VPN-Verbindungsanfrage von Android.
3. Optional: Aktivieren Sie in den Android-Einstellungen **Durchgehend aktives VPN** und **Verbindungen ohne VPN blockieren**.

### Smart-TVs und Streaming-Sticks

Viele Anbieter bieten Apps für Android TV und Amazon Fire TV an. Für Fernseher ohne VPN-Apps nutzen Sie stattdessen einen VPN auf Ihrem Router.

### Router

Ein VPN auf dem Router schützt jedes Gerät in Ihrem Zuhause, auch Spielkonsolen. Dafür brauchen Sie einen kompatiblen Router und etwas Geduld; folgen Sie Schritt für Schritt der Router-Anleitung Ihres Anbieters.

## Schritt 4: Verbinden

Tippen Sie auf **Verbinden** oder **Schnellverbindung**. Die App wählt einen schnellen Server in Ihrer Nähe. Um zu prüfen, ob alles funktioniert, öffnen Sie unser Tool [Wie ist meine IP?](/tools/what-is-my-ip/) – Sie sollten den Standort des VPN-Servers statt Ihres eigenen sehen.

## Schritt 5: Diese Einstellungen ändern

- **Kill Switch: an.** Blockiert den Internetverkehr, wenn die VPN-Verbindung abbricht, sodass Ihre echte IP nie offengelegt wird. [Mehr erfahren](/guides/what-is-a-kill-switch/).
- **Protokoll: WireGuard (oder die Variante Ihres Anbieters).** Meist die schnellste und modernste Option. [Protokolle vergleichen](/guides/wireguard-vs-openvpn/).
- **Automatisch verbinden in nicht vertrauenswürdigen WLANs: an.** So sind Sie in Cafés und Hotels geschützt, ohne daran denken zu müssen.
- **Bedrohungs-/Werbeblocker: optional.** Viele Anbieter blockieren bekannte schädliche Domains.

## Fehlerbehebung

- **Langsame Verbindung?** Wählen Sie einen Server in Ihrer Nähe oder wechseln Sie das Protokoll. Siehe [Macht ein VPN das Internet langsamer?](/guides/does-a-vpn-slow-down-internet/)
- **Eine Website blockiert Sie?** Probieren Sie einen anderen Server oder nehmen Sie diese App per Split Tunneling aus.
- **Keine Verbindung in einem bestimmten Netzwerk?** Manche Netzwerke blockieren VPN-Ports; wechseln Sie das Protokoll oder wenden Sie sich an den Support.

## Nutzen Sie ihn rechtmäßig

VPNs sind in den meisten Ländern legal, aber nicht in allen. Prüfen Sie die [VPN-Legalität nach Land](/vpn-legality/), bevor Sie im Ausland einen VPN nutzen.
