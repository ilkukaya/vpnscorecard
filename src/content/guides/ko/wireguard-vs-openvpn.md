**VPN 프로토콜**은 VPN 앱이 암호화된 터널을 만들 때 사용하는 규칙의 집합입니다. 대부분의 앱에서 프로토콜을 선택할 수 있으며, 이 선택은 속도, 배터리 수명, 안정성에 영향을 줍니다.

## WireGuard 한눈에 보기

WireGuard는 현대의 표준입니다. 코드가 오래된 프로토콜에 비해 매우 작아(수십만 줄 대비 수천 줄), 감사하기 쉽고 버그가 숨어 있을 가능성도 적습니다.

- **속도:** 대개 가장 빠르며 지연 시간이 짧습니다.
- **보안:** 취약한 레거시 옵션이 없는 최신 암호화 기술을 사용합니다.
- **모바일:** Wi-Fi와 모바일 데이터 사이를 전환할 때 거의 즉시 재연결됩니다.
- **개인정보 보호 관련 주의점:** 신뢰할 수 있는 제공업체는 IP 주소가 서버에 보관되지 않도록 자체 시스템을 추가합니다. NordVPN의 NordLynx가 한 예입니다.

## OpenVPN 한눈에 보기

OpenVPN은 약 20년 동안 업계의 주력 프로토콜이었습니다.

- **속도:** 대부분의 연결 환경에서 WireGuard보다 눈에 띄게 느립니다.
- **보안:** 제대로 설정하면 매우 성숙하고 광범위하게 감사를 받은 프로토콜입니다.
- **유연성:** 일반적인 보안 웹 트래픽처럼 보이는 TCP 443 포트로 실행할 수 있어, 다른 VPN 트래픽을 차단하는 네트워크에서도 작동합니다.

## 나란히 비교

| | WireGuard | OpenVPN |
|---|---|---|
| 속도 | 매우 빠름 | 보통 |
| 코드 크기 | 매우 작음 | 큼 |
| 모바일 재연결 | 즉시 | 더 느림 |
| 제한적인 네트워크에서 작동 | 차단될 때가 있음 | 좋음(TCP 443) |
| 성숙도 | 비교적 새로움(Linux에는 2020년 도입) | 매우 성숙함 |

## 무엇을 선택해야 할까?

1. 기본적으로 **WireGuard를 사용하세요**(또는 제공업체의 WireGuard 기반 프로토콜).
2. 호텔, 학교, 회사 네트워크가 VPN을 차단한다면 **OpenVPN TCP로 전환하세요**. 단, VPN 사용이 허용된 곳에서만 그렇게 하세요.
3. 네트워크를 이동하면서 최대한의 안정성이 필요하다면 iPhone에서 **IKEv2를 사용해 보세요**.
