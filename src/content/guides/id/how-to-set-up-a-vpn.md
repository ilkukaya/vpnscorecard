Memasang VPN jauh lebih mudah daripada kedengarannya. Untuk sebagian besar perangkat, prosesnya kurang dari lima menit.

## Langkah 1: Pilih VPN

Pilih penyedia dengan kebijakan no-logs teraudit, aplikasi untuk semua perangkat Anda, dan garansi uang kembali agar Anda bisa mengujinya. [Peringkat](/) dan [kuis pencari VPN](/quiz/) kami dapat membantu. Hindari VPN gratis tak dikenal dari toko aplikasi — lihat [apakah VPN gratis aman?](/guides/are-free-vpns-safe/)

## Langkah 2: Buat akun Anda

Daftar di situs web resmi penyedia. Paket jangka panjang biasanya jauh lebih murah per bulannya, tetapi paket bulanan tidak masalah jika Anda ingin mencoba terlebih dahulu. Perhatikan masa pengembalian dananya.

## Langkah 3: Instal aplikasinya

Selalu unduh aplikasi dari situs web penyedia atau toko aplikasi resmi.

### Windows dan Mac

1. Unduh penginstal dari situs web penyedia.
2. Jalankan dan ikuti petunjuknya. Di macOS, izinkan konfigurasi VPN saat diminta.
3. Masuk dengan akun Anda.

### iPhone dan iPad

1. Instal aplikasi penyedia dari App Store.
2. Masuk dan ketuk **Connect**.
3. Ketuk **Allow** saat iOS meminta untuk menambahkan konfigurasi VPN.

### Android

1. Instal aplikasi dari Google Play.
2. Masuk dan ketuk **Connect**, lalu terima permintaan koneksi VPN dari Android.
3. Opsional: di pengaturan Android, aktifkan **VPN selalu aktif** dan **Blokir koneksi tanpa VPN**.

### Smart TV dan stik streaming

Banyak penyedia menawarkan aplikasi untuk Android TV dan Amazon Fire TV. Untuk TV tanpa aplikasi VPN, gunakan VPN di router Anda sebagai gantinya.

### Router

VPN di router melindungi setiap perangkat di rumah Anda, termasuk konsol. Cara ini memerlukan router yang kompatibel dan sedikit kesabaran; ikuti panduan router dari penyedia Anda langkah demi langkah.

## Langkah 4: Sambungkan

Ketuk **Connect** atau **Quick connect**. Aplikasi akan memilih server cepat di dekat Anda. Untuk memastikan VPN berfungsi, kunjungi alat [Berapa IP saya](/tools/what-is-my-ip/) kami — Anda seharusnya melihat lokasi server VPN, bukan lokasi Anda sendiri.

## Langkah 5: Ubah pengaturan berikut

- **Kill switch: aktif.** Memblokir lalu lintas internet jika VPN terputus, sehingga IP asli Anda tidak pernah terekspos. [Pelajari lebih lanjut](/guides/what-is-a-kill-switch/).
- **Protokol: WireGuard (atau versi WireGuard dari penyedia).** Biasanya opsi tercepat dan paling modern. [Bandingkan protokol](/guides/wireguard-vs-openvpn/).
- **Sambung otomatis di Wi-Fi yang tidak tepercaya: aktif.** Agar Anda terlindungi di kafe dan hotel tanpa perlu memikirkannya.
- **Pemblokir ancaman/iklan: opsional.** Banyak penyedia memblokir domain berbahaya yang sudah dikenal.

## Pemecahan masalah

- **Kecepatan lambat?** Pilih server yang lebih dekat dengan Anda atau ganti protokol. Lihat [apakah VPN memperlambat internet?](/guides/does-a-vpn-slow-down-internet/)
- **Sebuah situs memblokir Anda?** Coba server lain atau gunakan split tunneling untuk mengecualikan aplikasi tersebut.
- **Tidak bisa terhubung di suatu jaringan?** Beberapa jaringan memblokir port VPN; ganti protokol atau hubungi dukungan.

## Gunakan secara sah

VPN legal di sebagian besar negara, tetapi tidak di semua negara. Periksa [legalitas VPN per negara](/vpn-legality/) sebelum menggunakan VPN di luar negeri.
